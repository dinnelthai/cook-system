# B06 — project financial close review
The terminal now exposes Financial Close Review for an explicitly imported closed-interval report. Cash, creator receivables and PnL are obtained from the existing audit computation, not caller-supplied derived totals. A separate historical balance-sheet view exposes inventory marks only if supplied endpoint arithmetic reconciles (including synthetic reports); missing endpoints are null. NAV residual is a descriptive unexplained component, not a profit or a reconciliation certification. Gross interval capital contributions and withdrawals are separate from net trade cash movement, income and expenses. Opening cash is not lifetime investment. A failed terminal audit withholds all final totals. Export is a derived review and cannot authorize actual settlement or be used as a raw historical input. No future sell quote, trade execution, wallet operations, or real asset settlement. Real source, ownership and valuation evidence remain unknown. UI uses existing project report import and navigation; local browser acceptance remains pending.
