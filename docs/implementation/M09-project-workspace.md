# M09-A — portable historical project workspace
Project identity is separate from closed-interval report identity. Fully declared network/genesis/project/token/quote/source tuples group records; incomplete identities remain isolated. This is not independent source or wallet attribution. No financial aggregation across intervals or networks.
The Projects page explicitly exports a versioned JSON workspace of original inputs and merges an imported workspace by re-auditing every member into a fresh catalogue. A conflicting or invalid record leaves the original catalogue unchanged. Existing capacity is eight reports / 16 Mi characters; file chooser cap is 64 MiB. Only sanitized reports should be exported. No auto-saving private evidence to browser storage.
Persistence is portable file-based, not automatic refresh restoration or a database. Actual browser acceptance, durable transactional server storage and multi-user concurrency remain open. No change to terminal, wallet selection, trade permissions or live execution.
