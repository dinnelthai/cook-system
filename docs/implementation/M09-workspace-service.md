# M09-C — explicit local historical workspace UI and service
Set COOK_HISTORICAL_WORKSPACE=1 when starting scripts/serve-offline-mvp.mjs; default off. Optional COOK_HISTORICAL_WORKSPACE_DB matches the CLI path override. The default is the repository's ignored .cook-system/historical-workspace/workspace.sqlite. Node 22.13+ or 24. The existing loopback/Host/Origin boundary applies; no RPC or wallet changes. Only sanitized original report inputs; no encrypted storage or multi-user authorization.
Projects page: explicitly load the latest revision (replaces session catalogue after confirmation when nonempty), save after loading the current version, list revision metadata. No automatic saves. A failed/ambiguous save clears the known revision; export the current session before reloading, then explicitly reconcile changes. No automatic retries or overwrites. A successful response never updates terminal data or wallet selection. Historical revision content remains available through the existing CLI export.
HTTP GET /api/historical-workspace; POST same path with workspace and expectedRevision; GET /api/historical-workspace/revisions. Disabled returns 503; stale revision 409. HTTP tests cover the handler/client, not browser DOM or the full server authorization path. Actual local browser, permissions, backups and multi-user acceptance remain pending.
