# Local test wallet configuration

No browser wallet is required by the accounting demo. Copy config/local-wallet.example.json outside the repository and replace the placeholders with the test environment's genesis hash and public fee-payer identifier. No private keys, seed phrases or signing services are accepted. The existing isolated test environment remains responsible for authorized test transactions and network fees.

After a closed test interval, export independently verified receipts in a JSON object with observedGenesisHash, historyComplete and receipts. Each receipt contains signature, genesisHash, feePayerPublicKey, finality, reconciliation, outcome and feeLamports (integer string). Run node scripts/audit-local-wallet-fees.mjs CONFIG.json RECEIPTS.json. The CLI accounts for verified successful and failed transaction fees; it never constructs or submits transactions or debits balances. Configuration does not authenticate a network on its own; the environment must independently attest the genesis hash and actual receipts. The report is a standalone historical audit and is not yet integrated into the frontend or the remote test API. No actual signing or fee payment is implemented in Cook System.
