# T19 — Trade 多钱包买卖需求拆解与现状审查

基线：36e628247112d52f803317e4e22c5e4908f0bad6（main）。
性质：需求评审文档，不是开发任务书；不修改业务代码、UI、CSS、网络配置、交易执行权限。不是 Codex 执行任务。

## 1. 产品区域和现状

| 区域 | 业务语义 | 当前源码事实 |
|---|---|---|
| Select Token | 明确当前 Token 与所属网络、市场 | 仅允许已注册 Localnet Token；市场另需验证 |
| Wallets | 查看多钱包资产、选择需审查的钱包 | 支持列表、多选与真实 RPC 观察；交易票据仍限制在项目范围 |
| Set amounts | 参考 UI 表达买入金额或卖出比例 | openAmountsPreview 未接钱包数据，提交禁用；Same for all / Random range / 百分比为界面预览 |
| Bundle Buy / Sell | 界面表达多个钱包的买卖意图 | 切换方向只改变显示，按钮禁用，无执行链路 |
| TX count / Total amount | 区分请求数、历史成交数、计划金额、实际成交额 | 当前显示占位值，不是已验证统计 |
| TX Delay / Estimated Interval / Estimated Time | 参考界面中的时间相关概念 | 延迟控制禁用，时间显示为占位值 |
| Dump It | 界面表达退出持仓的意图 | 按钮禁用，金额与收益占位值；不是可执行清算服务 |
| Trades Log | 历史成交记录与查询 | T07 已绑定有限范围的 finalized、单一且余额核对通过的 PumpSwap 收据 |
| Single Wallet Trade | 独立单钱包交易输入检查 | 当前仅校验金额和已观察余额；没有真实报价或提交 |
| 后端交易接口 | 交易权限边界 | /api/local-wallet/trade 固定拒绝 PROJECT_EXECUTION_DISABLED |

## 2. 需求分解（评审和只读核对）

| ID | 需求子项 | 评审交付及验收 |
|---|---|---|
| T19.01 | 市场上下文 | 明确 Mint、网络、已注册市场；历史或另一网络数据不能串入 |
| T19.02 | 钱包资产与归属 | 核对公开地址、余额状态、项目范围；选择列表不代表交易授权或独立市场参与者 |
| T19.03 | Set amounts 语义 | 记录现有单位、输入提示、方向切换、未知余额等界面状态；不生成或保存多钱包金额分配 |
| T19.04 | Buy/Sell 语义 | 记录意图与真实成交的区别，按钮当前不可执行；不要把预览当作订单 |
| T19.05 | 数量及金额口径 | 文档定义历史收据数、成交事件数、实际用户报价额、网络费用等独立指标；不将意图、交易或 bundle 混计 |
| T19.06 | 时间口径 | 记录真实历史确认时间、观测时间与缺失状态；不设计多钱包调度或交易时序 |
| T19.07 | 退出与收益 | 区分现有持仓、已实现收益、未实现估值、实际历史净收款；无完整成本或估值证据时保持未知，不推导协同退出 |
| T19.08 | 成交日志 | 审查筛选、排序、签名去重、失败/普通转账排除、历史覆盖有限的提示 |
| T19.09 | 独立单钱包交易 | 审查现有输入校验、余额及费用缺口、单笔授权语义；本任务不新增交易能力 |
| T19.10 | 风险与验收 | 检查跨网络/跨 Token 数据混用、错误数据、未经授权操作、虚假活动展示及证据缺失；原执行边界保持有效 |

## 3. 依赖关系

- T01–T05：RPC、资产、Token 和范围信息。
- T06：历史/索引行情。索引身份与独立来源认证不是同一件事。
- T07：有证据的历史成交日志，不代表完整历史。
- T08：历史收益核算，不能直接推导实时 Profit。
- T12：独立交易报价与风险语义评审。当前未实现真实报价服务。
- T18：开发阶段结束后统一联调上述已经提交的代码；T19 本身只验收文档与现状准确性。

## 4. 风险与明确排除范围

多钱包管理、公开资产查询和历史成交分析属于正常用途。不能把关联钱包活动描述成独立用户需求，不能把自成交、对敲或虚假成交量当作真实市场质量。针对先前讨论的操纵性用途，本评审不提供协同买卖执行架构、批量签名/提交流程、金额分配算法、随机时序、隐藏关联钱包、同步派发或砸盘策略，也不将这些内容作为 Codex 待实施需求。不得将既有禁用按钮当作已上线功能。若独立正常交易另有需求，应单独明确用途和授权边界后评审。
