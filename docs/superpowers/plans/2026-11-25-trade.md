# Localnet Trade Implementation Plan

**Goal:** Project-bound multi-wallet Localnet trade with explicit preview and verifiable results.
**Architecture:** Validate project and registered managed wallets at the server boundary; preview and execute only against pinned project and market context. Preserve the legacy disabled endpoint. Execution requires durable idempotency and recovery; UI presents only supported capabilities.
**Tech Stack:** Node.js ES modules, SQLite, existing PumpSwap SDK and browser UI.
**Spec:** docs/implementation/trade-development-brief.md

- [ ] Implement Localnet execution and integrate project API.
